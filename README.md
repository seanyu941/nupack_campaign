**NUPACK Campaign**

Script for Yale iGEM 2026-27 Estraflow project. Uses NUPACK to model binding interactions between a list of candidate cDNA sequences against a target aptamer. Outputs binding free energy and equilibrium concentrations.
Ran against 400 pilot candidates, pushing 10 oligos to wet-lab validation and reducing experimental burden by 97.5%.

**Requirements**
- Working NUPACK installation
- Working Pandas installation
